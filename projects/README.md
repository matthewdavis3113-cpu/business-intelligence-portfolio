NFL Player Performance Analysis

Project Overview

This project will analyze NFL player performance statistics to identify trends, evaluate player production, and explore how data can support team decision-making.

Business Objective

The goal is to determine how player performance data can help NFL organizations make better decisions regarding player evaluation, roster construction, and salary allocation.

Questions to Investigate

Which players are producing the most?

How does player performance change throughout a season?

Which players provide the greatest value relative to their salary?

Are there measurable differences in performance against different defensive schemes?

How can teams use performance data to make better roster decisions?
